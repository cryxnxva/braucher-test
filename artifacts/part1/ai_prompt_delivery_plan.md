# План отправки промпта в чат

`output/ai_prompt.txt` разбит на части, чтобы текст дошёл до модели целиком. Всего частей: 4. Части идут строго по порядку, каждая одним сообщением: сначала служебная фраза (если она нужна), затем содержимое файла.

| --- | --- | --- | --- |

| 2 | `ai_prompt_part02.txt` | 49828 | 442 |
| 3 | `ai_prompt_part03.txt` | 49924 | 527 |
| 4 | `ai_prompt_part04.txt` | 30940 | 391 |

Итого: 180684 символов, 1712 строк отзыва.

## Пошагово

### 1. Открой новый чат и отправь сообщение:

```text
Я пришлю данные для анализа частями. Не начинай анализ, пока я не пришлю сообщение "Данные закончились".
```

### 2. Открой `ai_prompt_part01.txt` и отправь его содержимое следующим сообщением.

Внутри файла уже есть первая строка инструкции и шапка товара 1 — ничего дописывать не нужно.

### 3. Для каждой следующей части (кроме последней) — сначала фраза:

```text
Продолжение, часть 2 из 4.
```

затем содержимое `ai_prompt_part02.txt`;

```text
Продолжение, часть 3 из 4.
```

затем содержимое `ai_prompt_part03.txt`;

### 4. Последняя часть — `ai_prompt_part04.txt`.

Отдельную фразу перед ней можно не писать: первая строка уже внутри файла (`[Продолжение данных, часть 4 из 4]`). Отправь содержимое файла как есть.

### 5. Сразу после последней части отправь:

```text
Данные закончились. Дай сводку по каждому из трёх товаров в формате из инструкции (калибровка масштаба + 4 подраздела) и в конце — сравнение трёх товаров в 2–3 предложениях.
```

## Что сохранить

- Полный ответ модели сохрани в `output/ai_summary.md`, заменив черновой вариант.
- Первой строкой файла укажи модель, которая давала ответ, например: `Модель: <название и версия>`.

## Примечания

- Служебная строка промпта (`Служебное: символов отзывов...`) в части не входит: это заметка про сборку файла, модели она не нужна.
- Лимит на часть — 50000 символов. Если в чате поле ввода вмещает меньше, уменьши `MAX_PART_SYMBOLS` в `split_ai_prompt.py` и запусти `python split_ai_prompt.py` ещё раз: `output/ai_prompt.txt` при этом не пересобирается.
- Если модель всё равно отвечает по одному товару, уменьши лимит ещё — причина обычно в обрезке длинного сообщения, а не в самих данных.
