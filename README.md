# BRAUCHER — тестовое задание

Проект собирает данные из API Wildberries по трём артикулам и готовит две части
отчётности. Работа ведётся в feature-ветках, по одной ветке на часть задания.

## Часть 1. Отзывы → ИИ-сводка

Сбор отзывов покупателей по артикулам через
`https://feedbacks-api.wildberries.ru/api/v1/feedbacks` и подготовка данных для
анализа языковой моделью: рейтинг, текст отзыва, плюсы, минусы.

Результат части:

- скрипт сбора отзывов;
- промпт, переданный модели;
- итоговая сводка по каждому товару (что хвалят, на что жалуются, что улучшить,
  о чём говорят чаще всего).

Готовые скрипты части: `explore_feedbacks.py` (разведка структуры ответа),
далее — сбор и выгрузка отзывов.

## Часть 2. Воронка продаж → мини-дашборд

Выгрузка данных воронки продаж за последние 7 дней (без сегодняшнего дня) через
`https://seller-analytics-api.wildberries.ru/api/analytics/v3/sales-funnel/products/history`
в Google Таблицу. Сырые данные по дням, расчёт показателей формулами таблицы:
конверсия (средняя / минимальная / максимальная), суммы заказов и выкупов за
период, средний чек, показы, сортировка по сумме выкупов по убыванию.

## Установка

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt    # Windows: .venv\Scripts\pip.exe
cp .env.example .env                          # Windows: copy .env.example .env
```

В `.env` заполнить `WB_TOKEN` (токен только на чтение) и `SPREADSHEET_ID` для
 Части 2. Файл `.env` и `credentials.json` не коммитятся.

## Запуск

```bash
python -m pytest                              # unit-тесты клиента WB API
python explore_feedbacks.py                   # дамп сырого ответа в output/
```

Скрипты создают каталог `output/` при запуске и пишут туда сырые дампы API.
